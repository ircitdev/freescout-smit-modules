# VoiceMail — голосовая почта → обращение и лид

Рабочий образец обработчика голосовой почты. Телефонная станция (мы использовали Mango Office) присылает письмо с записью и расшифровкой
в отдельный почтовый ящик FreeScout («Звонки»); модуль подхватывает такие обращения и превращает их в работу для людей.
Файл `Listeners/VoiceMailProcessor.php`:

1. достаёт номер клиента и номер, на который звонили; расшифровку берёт **из вложения письма станции** (Whisper и других распознавателей
   речи в модуле нет);
2. отсеивает мусор: односложные ответы, слишком короткие тексты, бессмыслицу;
3. ИИ (OpenAI) приводит расшифровку в читаемый вид и придумывает тему;
4. правила по ключевым словам определяют тип: проблема (поддержка) или подключение;
5. ищет абонента по телефону в REST API биллинга (константа `SMIT_BILLING_API`);
6. заводит обращение в нужном ящике («Поддержка клиентов» или «Подключение»), ставит теги по номеру и теме;
7. для подключения создаёт в AmoCRM контакт, лид и задачу «связаться»;
8. отправляет клиенту SMS через SMS Aero и закрывает исходную карточку голосовой почты.

## Настройка

* `.env`: `OPENAI_API_KEY`, `AMOCRM_DOMAIN`, `AMOCRM_ACCESS_TOKEN`, `SMSAERO_EMAIL`, `SMSAERO_API_KEY`. Отладочный файл
  `/tmp/voicemail_processor_debug.log` (в нём телефоны и тексты) включается только переменной `VOICEMAIL_DEBUG=true`.
* Константы в начале `VoiceMailProcessor.php`: ID ящиков и ответственного, номера телефонов (заглушки `7000000000N`), идентификаторы
  воронок и полей AmoCRM (нули). ID ящика голосовой почты есть и в `Console/Commands/ProcessVoicemail.php`, и в провайдере.
* Обращениям ставятся теги с номером линии (`attachTagsByDestination`) — для этого нужен модуль FreeScout Tags. Отдельного модуля метки канала
  у нас не было: заготовка `VoicemailLabel` так и не заработала (нет `start.php`), поэтому в репозиторий не вошла.
* Страница `/voicemail/settings` (только администратор) справочная: сохранить настройки через неё нельзя.

## Установка

```bash
cp -r VoiceMail /var/www/freescout/Modules/VoiceMail
cd /var/www/freescout
php artisan module:enable VoiceMail
php artisan cache:clear
```

Папка модуля должна называться ровно `VoiceMail`. Проверялось на FreeScout 1.8.x.
